[#reference-configuration]
= Configuration properties

Spring Boot reads these properties from `application.yml`, `application.properties`, environment variables and the command line.
<<appendix-config>> gives a full example.

[#reference-configuration-core]
== Core (`mifos.commons`)

[cols="3,1,2,4"]
|===
| Property | Type | Default | Description

| `mifos.commons.error-url`
| String
| `https://doc.mifos.org/projects/common/errors`
| The start of the `type` URL in error responses.

| `mifos.commons.tui-type`
| String
| -
| The command line module: `PICO` or `TAMBOUI`. If not set, no command line module starts.

| `mifos.commons.debug.cache-caffeine-enabled`
| Boolean
| `false`
| Makes the `CaffeineRemovalListener` bean.

| `mifos.commons.debug.cache-ehcache-enabled`
| Boolean
| `false`
| Makes the `EhcacheEventListener` bean.

| `mifos.banner`
| String
| -
| The text in the start banner after "Mifos - ".
|===

[#reference-configuration-persistence]
== Persistence (`mifos.commons.persistence.relational`)

[cols="3,1,2,4"]
|===
| Property | Type | Default | Description

| `mifos.commons.persistence.relational.enabled`
| Boolean
| `false`
| Reserved. The current version does not use this property.
|===

[#reference-configuration-rest]
== REST (`mifos.commons.transport.rest`)

[cols="3,1,2,4"]
|===
| Property | Type | Default | Description

| `mifos.commons.transport.rest.headers`
| List of strings
| -
| The request headers that the reactive web filter copies into the Reactor context. Use lower case names.

| `mifos.commons.transport.rest.default-page-number`
| Integer
| `0`
| The page number if a request does not give one.

| `mifos.commons.transport.rest.default-page-size`
| Integer
| `100`
| The page size if a request does not give one.

| `mifos.commons.transport.rest.error-url`
| String
| `https://doc.mifos.org/projects/common/errors`
| Reserved. Error responses use `mifos.commons.error-url`.
|===

The REST auto-configuration also reads `application.title` and `application.version` for the OpenAPI document.

[#reference-configuration-grpc-rsocket]
== gRPC and RSocket

The prefixes `mifos.commons.transport.grpc` and `mifos.commons.transport.rsocket` have the same properties as REST.
The current version does not use these properties.

[#reference-configuration-flow]
== Flows (`mifos.operation.flow`)

The operation starter reads these properties.
Each section is a map: the key is the name that a flow uses.

=== Boundaries (`mifos.operation.flow.boundaries.<name>`)

[cols="3,2,2,4"]
|===
| Property | Type | Default | Description

| `propagation`
| `required`, `requires-new`, `mandatory`, `supports`, `not-supported`, `never`, `nested`
| `required`
| The transaction propagation. The values agree with Spring `TransactionDefinition.PROPAGATION_*`.

| `read-only`
| Boolean
| `false`
| Makes the transaction read-only.

| `timeout`
| Duration
| -
| The transaction timeout, in whole seconds. If not set, the transaction manager gives the timeout.

| `transaction-manager`
| String
| -
| The bean name of the transaction manager. If not set, the primary transaction manager.
|===

Built-in boundaries:

[cols="1,3"]
|===
| Name | Values

| `required` | `propagation: required`
| `requires-new` | `propagation: requires-new`
| `read-only` | `propagation: required`, `read-only: true`
|===

=== Retry policies (`mifos.operation.flow.retry.<name>`)

[cols="3,2,2,4"]
|===
| Property | Type | Default | Description

| `max-attempts`
| Integer
| `3`
| The total number of attempts, with the first attempt.

| `initial-backoff`
| Duration
| `50ms`
| The delay after the first failed attempt.

| `multiplier`
| Decimal
| `2.0`
| The delay increases by this factor after each failed attempt.

| `max-backoff`
| Duration
| `1s`
| The maximum delay.

| `jitter`
| Decimal, 0 to 1
| `0.5`
| Each delay becomes shorter by a random fraction up to this value.

| `retry-on`
| List of class names
| `org.springframework.dao.ConcurrencyFailureException`
| The `RuntimeException` types that start a new attempt. Subclasses also start a new attempt.
|===

Built-in retry policy: `conflict`, with the default values.

=== Executors (`mifos.operation.flow.executors.<name>`)

[cols="3,2,2,4"]
|===
| Property | Type | Default | Description

| `virtual-threads`
| Boolean
| `true`
| Runs the parallel parts on virtual threads.

| `concurrency-limit`
| Integer
| `-1`
| The maximum number of parallel parts at the same time. `-1` means no limit.
|===

Built-in executor: `default`, with the default values.

NOTE: If you add a boundary, a retry policy or an executor with a built-in name, your values replace the built-in values.
