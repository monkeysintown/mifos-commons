= Introduction

{organization} Commons Boot is a set of libraries for Spring Boot applications.
The libraries give Mifos applications the same base for configuration, errors, persistence, transport and operations.

Use these libraries when you write a Mifos service in Java.
You get:

* An error model with codes, categories and translated messages.
* Auto-configuration for relational persistence, REST, gRPC and RSocket.
* Usecases: small units of business logic with a request and a response.
* Flows: business processes that you write as data and run with transactions, retries and parallel steps.
* Diagrams of your flows in PlantUML and BPMN format.
* Command line, banner and debug tools.

== Requirements

* Java 25 or later.
* Spring Boot 4.
* Gradle or Maven.
